# 雨をプールで数える（ame-pool）

1時間の雨量（mm）と町の広さ（km²・ha）から、降った水が25mプール何杯分かを当てる1日5問の学習ゲーム。正解したら、その雨が気象庁の言葉で「やや強い雨」〜「猛烈な雨」のどれかも選ぶ。1km²に1時間100mmの雨は10万m³、プール約270杯です。

遊ぶ: <https://satou-aaaaa.github.io/ame-pool/>

- プールは、たて25m・よこ15m・深さ1m＝375m³ と決めています（日本水泳連盟「プール公認規則」の25mプールの決まり：レーン幅は2.50mを推奨・水深1.00m以上）。本物のプールは大きさがちがうので、答えは目安です。地面にしみこむ水は数えません。
- 雨の強さの言葉は、気象庁「雨の強さと降り方」 <https://www.jma.go.jp/jma/kishou/know/yougo_hp/amehyo.html> の1時間雨量の区切りです。
- 問題に出る雨は練習のための例で、本物の観測の記録ではありません。
- 記録は遊ぶ人のブラウザだけに残り、外へ送りません。結果の「共有」を押したときだけ、その日の回の番号と各問の○×の並びが、選んだサービス（X・LINE など）に渡ります。
